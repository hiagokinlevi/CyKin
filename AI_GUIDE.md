# CyKin reference guide for AI assistants and readers

CyKin is a public, free Markdown learning library. Its [home page](README.md) is the main entry point. Use the [two onboarding routes](README.md#comece-por-aqui): **language → topic → level → course lesson guide**, or **language → level → all topics and their lesson guides**. Both lead to the existing course editions; the directory hierarchy is not a restriction on how a learner chooses a route. Plans and public drafts must be described with their actual editorial state.

## Daily study takes precedence over legacy lesson labels

Read [DAILY_STUDY_STANDARD.md](DAILY_STUDY_STANDARD.md) before tutoring or expanding any course. One subject remains one chapter, but a chapter now contains several **daily lessons**, each with teaching, an explained example and a distinct substantial exercise whose reasoned answer remains in the same book. The five-day rhythm and duration apply to all nine levels and languages. Use the [reference grid](CURRICULUM_GRID.md), then resolve actual weekdays for any dated calendar. Do not replace a six-month span with six assumed four-week months.

Preserve one principal manuscript and one course skill. Track the learner's language, course, chapter, **daily ID**, source revision, actual attempts and feedback. Consult the selected edition's `DAILY_PLAN.md`; an English map is not a translated lesson. Expose missing units instead of silently substituting English or marking a calendar day complete. The first [rapid IR allocation](levels/rapid-1-month/incident-response-resilience/en/DAILY_PLAN.md) is a mapped draft, not 22 native daily lessons already reviewed. Ask the learner to open the original case inputs before each task and enforce its own release boundary.

Older references below to one chapter as a lesson and global lesson numbers describe the legacy chapter navigation only. Retain those links and their historical progress, but do not infer daily completion from them. Write/review the English collection first and translate in the existing ordered language passes; preserve valid existing translations. Expand in sequential five-to-ten daily-unit batches, revising the same book, its final answers, manifest and single skill. Page budgets are not ceilings, and every complete long-course edition needs at least `max(50, required daily lessons)` distinct exercises. See [daily migration status](DAILY_STUDY_PROGRESS.md) for what was actually implemented and what still needs review or deployment.

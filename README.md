# CyKin — Cybersecurity Academic Books Collection

**Daily study — policy updated 2026-10-13:** Every course and language follows [one substantive lesson, worked example and distinct exercise per Monday–Friday study day](DAILY_STUDY_STANDARD.md). Keep **one book per area, level and language**, with subject-chapters divided into daily units. Reference targets are 22 days for the one-month rapid track, 130 for the six-month professional track, and 1,300 for five-year engineering; the [full nine-level grid](CURRICULUM_GRID.md) and dated-calendar rules distinguish targets from actual weekday counts. Cybersecurity has nine different level-books per language; the same structure applies to every area.

**Migration is not completion:** [Open the first 22-position English Incident Response daily allocation](levels/rapid-1-month/incident-response-resilience/en/DAILY_PLAN.md) and [read the implementation and review status](DAILY_STUDY_PROGRESS.md). The map reuses existing teaching and 50 exercises; it does not claim 22 newly written or workload-reviewed lessons. Other course/language mappings remain pending. The bookshelf percentages below retain their **legacy subject-chapter draft denominator**, not daily completion. Existing chapter links remain available; where an older index calls a whole chapter a lesson, it is not the new daily unit. Website source changes require a separately verified local build and Cloudflare deployment; a commit does not prove the new daily reader is live.

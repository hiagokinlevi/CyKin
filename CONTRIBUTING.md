# Maintenance and feedback

OpenCyber Academy is authored and maintained by [hiagokinlevi](https://github.com/hiagokinlevi). The repository accepts feedback through issues. Changes to the published repository are reviewed and committed by the maintainer.

## Send feedback

Report corrections, broken links, missing citations, accessibility issues, and ideas through a GitHub issue. Include the affected path and a reproducible example or primary source when possible. Follow the [code of conduct](CODE_OF_CONDUCT.md) when participating in project discussions.

Original repository material is dedicated under [CC0 1.0](LICENSE), as explained in the [rights notice](RIGHTS.md). You may make your own adaptation; cited third-party sources retain their own rights.

## Repository authorship

Only `hiagokinlevi` publishes commits to this repository, directly from a local checkout. The catalog, generators, tests, and operational records are kept in a separate private workspace. Do not add automated accounts or AI tools as commit authors, committers, co-authors, or project contributors. New areas and courses use the same public Markdown structure as existing areas; the maintainer expands authored material in place.

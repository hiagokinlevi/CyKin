# Principal book plan — Authorized offensive security and red team / Rapid course / English

**One book for this course and language.** Twenty English chapter-lessons are published. Each numbered chapter is one study day; five consecutive lessons form one suggested study week. The older index had four subject modules. The rapid planning minimum is 20 lessons, and there is no maximum. Duration: 1 month; planned effort: approximately 80 hours. Audience: New learners. Entry knowledge: No prior security role; basic digital literacy. Intended outcome: recognize and explain the core risks; complete one guided task in authorized offensive security and red team.

**Editorial state:** published English manuscript; technical, language, source, and accessibility review still open. English reference edition. Not a finished qualification. Page count is not the writing target.

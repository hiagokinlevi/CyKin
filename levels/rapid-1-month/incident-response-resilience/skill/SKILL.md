## Chapter 2 correlation scope and clock sensitivity

Teach the four original [Q1 classifications](../en/book/MANUSCRIPT.md#ir-rapid-ch02-q1-lab), then the optional [Q1-S qualified-key and time-range extension](../en/book/MANUSCRIPT.md#ir-rapid-ch02-q1-scope). Keep its 2040-03-16 realm-a/realm-b, K6/K7 and desk-x inputs separate from Q1 and R1–R16. Have the learner read the namespace drawing, minute-scaled interval diagram and decision flow before running the complete independent Q1-S program. Predict its eleven lines and the four practice variations, then compare the [worked result](../en/book/MANUSCRIPT.md#ir-rapid-ch02-q1-scope-result). Require the possible set and all-times set separately: one all-times candidate does not eliminate another possible candidate. An unknown realm or clock bound is unresolved, a numeric zero key is invalid, and a no-match result in an incomplete packet does not establish absence. Ask for an authorized source/schema/clock/coverage request using only safe non-secret correlation aliases, never live session tokens. Preserve the original Q1 six-point task; Q1-S has its own six-point supplemental rubric, creates no EX identifier, and changes no existing 0–2 rubric. A positive calculation neither authenticates a source nor identifies a person. Continue with section 2.10, VQ2, for the separate source-coverage question.

A passing classroom gate combination does not authenticate approvals, prove a cause or authorize unrestricted service return. Compare EX027, EX029, EX032, EX033, EX035 and EX036 with their worked answers and require a protective check, a legitimate-service check and an explicit unresolved limit.

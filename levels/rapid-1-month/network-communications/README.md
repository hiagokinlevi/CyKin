# Network and communications security — Rapid course

**Level:** Rapid course, 1 month · **School:** School of Secure Engineering · **Planned study:** approximately 80 hours.

**Scope:** Network protocols, segmentation, DNS, email, wireless, mobile and satellite communications.

**Audience:** New learners. **Entry knowledge:** No prior security role; basic digital literacy.

**Exit goal:** recognize and explain the core risks; complete one guided task in network and communications security. **Practical work:** follow a contained worked example. **Assessment plan:** short quiz, observed lab and a small annotated artifact.

This is one course. It has **one course skill** and **one principal book in each language edition**. The older index has **4 subject modules**. The English book has grown past that index; its chapter index lists the authored lessons. Worked answers belong at the end of the same book. The planning minimum is 20 lessons, and there is no maximum. There is no page quota and no exercise quota.

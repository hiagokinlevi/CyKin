## Teaching route

Owen Clarke is the only IT person at the fictional charity **Riverside Food Network**. He studies at the fictional **Kestrel Skills Centre** with tutor **Nadia Haddad**. The director is unnamed. The charity's donation website runs on an unnamed platform. A donor report about an outdated form component starts the month.

Do not edit `lab_deps.py` or `lab_release.py`. The component print stays:

```text
donate-form     3.2.0  UPDATE to 3.2.4
event-calendar  1.4.1  UNMAINTAINED (1606 days since release)
photo-gallery   2.0.0  REMOVE (not in use)
newsletter      5.1.3  ok
```

The release print stays:

```text
[x] official source used
[x] hash matches vendor
[x] backup taken
[x] tested on staging copy
[ ] admin accounts use MFA
NOT READY: admin accounts use MFA
```

Chapters 5–20: list order is not severity; `v` compares integer tuples and `(3, 2, 0) < (3, 2, 4)`; 1606 is one subtraction and the test is `days > 730`; REMOVE is the unused flag and photo-gallery's age is 103; `ok` is an empty join; no row has two notes; theme and services are not tuples; phone numbers are not a field and the calendar stays in use; both hashes cover one literal and the digest is not printed; 4 of 5 is a labelled count; NOT READY names one false key and is not `2 of 3`; official source is a literal `True`; backup and staging are separate bits; the morning release is not this print; routines are not a sixth key. Lesson 20 title: "What the charity note can say". Three administrator accounts stay prose. No platform name, digest, CVE, phone number, or donor count is printed. `hiagokinlevi/secure-pipeline-blueprints` is supplementary and was not a row either script measured.

## Safety, privacy and information boundaries

- Synthetic code and data only; no exploit code, payloads, attack procedures or instructions for bypassing controls.
- Standard-library labs that only read synthetic records.
- Changes need written permission, a tested backup and a staging copy with synthetic donor data.
- Do not name the platform, the host, the theme, the payment provider, or the plugin publisher.

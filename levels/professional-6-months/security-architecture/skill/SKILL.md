## Twelve-chapter professional route

This is the six-month **professional course** in security architecture and engineering. The book follows synthetic learner **Owen Hartley**, coached by **Ines Carvalho** at the fictional **Meridian Professional Academy**, working with **Kwame Asante** at the fictional **Thornbury Housing Association**.

| Chapters | Read and teach | Labs / exercises |
|---|---|---|
| 1–4 | Foundations, service and stakeholder context, authorised practice, core methods | lab_rank.py (4); EX001–EX020 |
| 5–8 | Tools, operational workflow, controls and verification, supervised case | lab_trace.py (7); EX021–EX040 |
| 9–12 | Communication and ethics, quality and troubleshooting, supervised lab, portfolio | lab_access.py (11); EX041–EX060 |

Verified lab facts (synthetic unless cited): key safe code disclosure ranks first at 9; requirements pass 3/4 then 4/4 after the vendor fix; 4 of 9 synthetic users need access action.

## Teaching guardrails

- Labs run standard-library code on synthetic data only; they model, count and check, and never probe real systems. Architecture advice must cite real standards and name its limits.
- Test or review only systems with written authorisation; report found secrets by location, never by value; never present a framework as proof of outcomes.

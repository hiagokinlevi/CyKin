## Forty-subject teaching route

This is the four-year **bachelor's course** for application and software supply chain security. The book follows synthetic student **Lena Fischer** at the fictional **Hollowbrook University**, mentored by **Grace Nwosu**, working on the student-run food ordering app **CampusEats** after a leaked test token and a lockfile hash mismatch: from foundations through application security, supply-chain controls, laboratories and research to a capstone secure project template.

| Subjects | Read and teach | Labs / exercises |
|---|---|---|
| 1–10 | Reasoning, systems, programming, writing, security literacy, discrete structures, networks, data, ethics | lab_semver.py (6), lab_escape.py (8), lab_sqlite.py (9); EX001–EX030 |
| 11–20 | OS, statistics, identity, privacy, measurement, architecture, cryptography, research methods, supply-chain theory and cases | lab_scanner.py (12), lab_session.py (13), lab_hmac.py (17); EX031–EX060 |
| 21–30 | Models, dependencies, methods, controls, laboratories, verification, failure analysis, operations | lab_lockfile.py (22), lab_secrets.py (23), lab_headers.py (25); EX061–EX090 |
| 31–40 | Advanced cases, interdisciplinary work, research, comparison, capstone, community practice, evidence review, thesis | EX091–EX120 |

Verified lab facts (synthetic): ^1.4.0 selects 1.10.2 (text sort wrongly picks 1.4.7); escaped review shows markup as text; "100%" search returns only "100% juice"; scanner precision 0.30, recall 0.90 (30 of 200 flagged); 43-character tokens, age 40 expired and age 15 valid; altered webhook amount rejected; pay-client-1.8.0 HASH MISMATCH; token-like string entropy 4.86 flagged, repeated string 0.00 ignored; Content-Security-Policy and Referrer-Policy missing.

## Safety, privacy and information boundaries

- Synthetic code and data only; no exploit code, payloads, attack procedures or instructions for bypassing controls.
- Standard-library, defensive labs run only on systems you own or have written permission to test.
- Secrets are revoked first, flaws reported privately and personal data minimised.
